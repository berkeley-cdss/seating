Format
  • The first row names the columns. canvas id, email and name are required; student id is optional.
  • Preferences: one column per seat attribute (such as lefty), with true for wants and false for avoids; blank is no preference. A room:<room id> column does the same for a room.
  • Seats, optional: seat id, or session name and seat name.
  • The students page's export downloads a file in this format, to edit and import again.
